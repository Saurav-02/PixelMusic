Source Transparency & Integration

Offline storage, self-hosted servers, and direct web streaming.

PixelMusic brings three distinct listening sources together under one unified interface:

  • 1. 100% Offline Local Playback: Reads internal storage and SD cards via Android MediaStore. Downloads embed full ID3/MP4 metadata and synced .lrc lyrics via TagLib & JAudioTagger.
  • 2. Self-Hosted Cloud Libraries: Native Subsonic API compatibility (Navidrome, Gonic, Airsonic) and Jellyfin media server streaming with two-way scrobbling and remote playlist sync.
  • 3. Direct Online Streaming: Direct GoogleVideo CDN streaming engine for YouTube & YouTube Music. Streams unencrypted Opus and AAC streams directly with zero tracking, no ads, and multi-account switching.

04 / About PixelMusic

Built in the open.
Shaped by listening.

PixelMusic is an open-source Android music player focused on an uncompromising daily listening experience. It combines expressive Material 3 design with bit-perfect audio playback, offline downloads, lyrics, self-hosted cloud integrations, and deep system-level Android features.

The project is developed by Saurav Biswas, with UI makeover and design collaboration from @Xyg901, and builds upon and credits the open-source PixelPlayer project by Theo Vilardo.
